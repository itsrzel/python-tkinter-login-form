# Python Tkinter Login Form

## Project Description
This project is a desktop login application developed using Python and Tkinter. It provides a simple graphical user interface where users can enter their username and password to access the system.

## Features
- Username and password input fields
- Password masking for privacy
- Login validation
- Successful login notification
- Failed login notification
- Customized GUI design using Forest Green and Gold colors
- Times New Roman font styling
